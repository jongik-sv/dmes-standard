# docs/mqc — 품질(MQC) 모듈 문서

실 프로젝트에서 이 디렉터리는 품질 모듈의 설계·이행 문서를 담는다.
화면 설계 문서를 모으는 `design/`, 산출물 목록을 관리하는 `manifest/`,
화면 그룹별 디렉터리, 테이블 목록 스프레드시트, 데이터 이행(마이그레이션) 문서,
이행 스크립트를 두는 `sql/` 로 구성된다.

본 템플릿에서는 고객사 품질 업무·테이블·이행 스크립트를 모두 제거하고,
검사 화면 설계서 형식을 보여 주는 샘플 1건만 남겼다.
