# MQC — 샘플 검사실적 등록 기능설계서 (예시)

> 템플릿용 축약 예시다. 실제 설계서는
> [`docs/guide/design/templates/기능설계서.template.md`](../../guide/design/templates/기능설계서.template.md) 를 따른다.

## 1. 화면 개요

| 항목 | 값 |
|---|---|
| 화면 ID | SAMPLE-INSP-001 |
| 화면명 | 샘플 검사실적 등록 |
| 업무 목적 | 검사의뢰 건에 대해 검사 결과를 등록하고 합·부를 판정한다 |
| 화면 유형 | 마스터-디테일 (의뢰 헤더 + 검사항목 라인) |

## 2. 화면 영역 정의

| 영역 ID | 영역명 | 설명 |
|---|---|---|
| A-FILTER | 조회조건 | 의뢰번호·검사일자·판정상태 |
| A-MASTER | 의뢰 헤더 | 품목·수량·의뢰자 |
| A-DETAIL | 검사항목 그리드 | 항목별 측정값 입력 |

## 5. 버튼 및 기능 동작 정의

| 버튼 ID | 명칭 | 동작 |
|---|---|---|
| BTN-001 | 조회 | 조건에 맞는 검사의뢰 목록 조회 |
| BTN-002 | 저장 | 측정값 검증 후 저장 (판정은 미확정 유지) |
| BTN-003 | 판정확정 | 전 항목 입력 완료 시에만 활성 |

## 6. 입력값 검증 규칙

- 측정값은 항목별 규격 하한 ≤ 값 ≤ 상한 범위 밖이면 경고를 띄우되 저장은 허용한다.
- 판정확정 시에는 미입력 항목이 하나라도 있으면 차단한다.

## 7. 상태 정의 및 상태별 제어

| 상태 | 설명 | 측정값 편집 | 판정확정 |
|---|---|---|---|
| REQUESTED | 의뢰접수 | 가능 | 불가 |
| IN_PROGRESS | 검사중 | 가능 | 가능 |
| JUDGED | 판정완료 | 불가 | 불가 |

## 11. 특이사항 / 설계 결정

- [확인필요] 판정확정 후 정정이 필요한 경우의 취소 경로 — 현업 확인 대기.
