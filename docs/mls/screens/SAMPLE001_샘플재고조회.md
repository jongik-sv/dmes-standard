# SAMPLE001 비즈니스 프로세스 분석서 (BPA) — 샘플 재고조회

> 템플릿용 뼈대다. 실제 보고서는 `generate-bpa` 스킬이
> `.claude/skills/generate-bpa/templates/bpa_report_template.md` §1~11 + §A 를 채워 생성한다.

## 1. 시스템 개요

가상의 창고 재고 현황을 품목·창고 단위로 조회하는 화면. 조회 전용.

## 2. 시스템 목적

현재고와 가용재고의 차이를 담당자가 즉시 확인할 수 있게 한다.

## 3. 핵심 워크플로우

```mermaid
flowchart LR
  S((시작)) --> P1[조회조건 입력]
  P1 --> P2[재고 현황 조회]
  P2 --> P3[결과 목록 표시]
  P3 --> E((종료))
```

## 4. 상세 워크플로우

- **P-01 조회조건 입력** — 품목·창고·기준일을 지정한다.
- **P-02 재고 현황 조회** — 기준일 시점 수량을 집계한다.

## 5. 비즈니스 로직 상세

- **BR-01** 기준일 미지정 시 당일로 간주한다.
- **BR-02** 가용재고 = 현재고 − 예약수량. 음수는 0으로 표시하지 않고 그대로 노출한다.

## 7. 주요 유즈케이스

- UC-01 담당자가 특정 품목의 창고별 재고를 확인한다.

## 8. 화면 구성 개요

상단 조회조건 영역 + 하단 결과 그리드 단일 구성.

## 9. 관련 엔티티

| 엔티티 | 역할 | 핵심 컬럼 |
|---|---|---|
| SAMPLE_STOCK | 재고 잔량 | ITEM_CD, WAREHOUSE_CD, QTY |
| SAMPLE_ITEM | 품목 기준정보 | ITEM_CD, ITEM_NM, UOM |

## 11. 특이사항 및 주의사항

1. 조회 전용 화면이므로 등록/수정 프로세스가 없다.
