### 3.3 MAIN 내부 배치

#### 3.3.1 사람·역할 그룹·역할 칸 (A-GRID)

각 행은 두 줄이다. 체크박스는 역할 그룹 칸(사람 ↔ 그룹), 역할 칸(그룹 ↔ 역할)에만 있다.

```
사람 칸 행            역할 그룹 칸 행              역할 칸 행
┌─────────────────┐  ┌──────────────────────┐   ┌──────────────────────┐
│ 김도윤  [사용 안 함]│  │☑ 냉연 조업 [추가] [바뀜] │   │☑ ▒냉연 조업자▒ [추가]   │
│ 냉연생산팀 · 그룹 2개│  │  역할 2개 · 사람 186명  │   │  메뉴 N개 · 사람 N명     │
└─────────────────┘  └──────────────────────┘   └──────────────────────┘
```

- 고른 행은 배경을 `--color-selection` 으로 바꾸고 오른쪽에 `›` 를 둔다.
- 체크하지 않은 그룹·역할 행은 눌러도 고를 수 없다(비활성). 마우스를 올리면 「체크해 넣으면 고를 수 있습니다」 툴팁을 보인다.
- 행 왼쪽 띠: 초록 = 추가, 빨강 = 삭제(이름에 취소선), 주황 = 바뀜. 같은 뜻의 작은 뱃지도 붙인다(색만으로 구분하지 않는다).
- 칸 머리 오른쪽: 편집(연필), 추가(+) 아이콘 버튼. 모두 원래 화면을 여는 링크이고 툴팁은 「{동작} - {화면 이름}에서 엽니다 ↗」 이다.

#### 3.3.2 메뉴 칸 (A-GRID-EXT)

```
┌ 메뉴(오브젝트)  [등록 N]                         (↗ 메뉴 수정) (↗ 오브젝트 수정) (↗ 오브젝트 추가) ┐
│ 「{역할}」의 메뉴. 체크 = 등록(퍼미션 행 있음) ...                                              │
│ [찾기............] [등록된 것|모두] [모두 펼치기] [모두 접기]                                    │
│ □  메뉴 · 화면                       버튼   초안                                              │
│ ▣  ▾ 공통관리                        4      +2 -1 ~1       ← 모듈 행 (세 상태 체크)            │
│ ▣    ▾ 시스템관리 ✎(↗)               3                       ← 폴더 행 (연필 = GB-004)        │
│ ☑      권한 작업대 commPermBench      4/11  [버튼]          ← 메뉴 행 (체크 = GB-007)         │
└───────────────────────────────────────────────────────────────────────────────────────────┘
```

- 들여쓰기: 모듈 0, 폴더 1단, 메뉴 2단.
- 세 상태 체크는 아래 메뉴가 모두 등록이면 체크, 일부면 중간 상태이다.
- 시스템 관리자 역할을 고르면 모든 체크가 잠기고 「시스템 관리자는 모든 메뉴를 받아 등록을 바꿀 수 없습니다」 안내가 뜬다.
- 초안 열: 모듈·폴더 행은 아래 변경 합계(`+등록 -해제 ~버튼`)를 보이고, 메뉴 행은 「등록」, 「해제」, 「버튼」 뱃지를 보인다. 이름·위치·표시 변경 뱃지는 없다. 초안이 USER_GRP, GRP_ROLE, ROLE_OBJ 3종만 담기 때문이다(Q-039).
- 메뉴 트리는 전체(1,004줄 규모)를 한 번에 받는다. 접힌 행은 그리지 않는다.

│   「역할」 × 「메뉴」  PK ROLE_ID = … OBJECT_ID = …                                       │
│   버튼 권한 BTN_PERM  [find][save ＋추가][delete −삭제] ...  (D-001 칩 묶음)               │

│   바꾼 것 (× 하나씩 되돌리기)  ·  영향받는 사람 표 (얻음 / 잃음, 12명 + 모두 보기)          │
└──────────────────────────────────────────────────────────────────────────────────────────┘

- 앱 창 안 메뉴 트리: 보이는 메뉴만(`G6-008 VISIBLE = Y`). 「초안」 보기에서 새로 보이는 메뉴는 초록 점, 사라진 메뉴는 취소선과 빨강 글씨로 남긴다.
- 메뉴 이름 옆의 역할 이니셜 칩(시안 `mock-v16.html:1469-1477`)은 두지 않는다. 계약에 그 데이터가 없다(Q-030, 다음 회차 후보).
- 버튼 칩: 켜짐 = 채움, 잠김 = 점선과 자물쇠 아이콘. 초안과 현재 값이 다르면 초록 테두리 + 「새로」, 빨강 테두리 + 「잃음」(오브젝트에서 빠졌으면 「버튼 없어짐」) 을 붙인다.
- 칩에 마우스를 올리면 이유 문구를 툴팁으로 보인다(기능설계서 §10 LV-004). 키보드로도 칩에 포커스를 줄 수 있다(`tabindex=0`).
- 「이 메뉴를 연 역할」 목록은 사람 기준에서는 사람이 받은 역할, 역할 기준에서는 고른 역할만 보인다(Q-009).
- 영향 사람 표: 12명까지 보이고 「N명 모두 보기」 로 펼친다. 응답이 500줄에 닿으면 「앞 500줄만 보입니다」 안내를 붙인다.

### 4.3 그리드 행 조건별 표시

| 조건 | 표시 방식 | 비고 |

| 숨김 메뉴 (SHOW_TP = N) | 「숨김」 뱃지, 미리보기 앱 창에서는 빠진다 | 주소로는 열린다 |

| 시스템 관리자 역할 | 체크와 칩이 모두 잠긴다 | 퍼미션 행이 없다(D13) |

- 선택 키 입력(역할 칩 편집 입력)이 필요한 곳은 `TokenChipInput` (신규 f1)을 쓸 수 있으나, 이 화면의 D-001, D-002 는 허용 값 안에서만 고르므로 `ToggleChipGroup` 만 쓴다.
- 공통 규칙: 응답 호출은 `useApiCall`, 사용자 메시지는 `useGfnMessage`(`@dk-oasis/shared/message-provider`)로 한다.
- 기존 shared 의 `layout/split-sizing.ts`, `ResizableFormPanel`, `grid-resize-box` 를 `ResizableColumns` 가 재사용할 수 있는지 f1 이 먼저 확인한다.

### 5.1 상호작용 규칙

| 규칙 | 설명 |
|---|---|
| 초안 저장 | 체크·칩 변경은 300 ms 모아 `saveDraft` 로 보낸다. 응답이 오기 전까지 화면은 변경을 먼저 보인다(낙관적). 실패하면 직전 초안으로 되돌리고 토스트를 보인다 |
| 초안 겹쳐 그리기 | G4, G5 체크는 `loadDraft` 의 변경(USER_GRP, GRP_ROLE)을 겹쳐 그린다. G6, G7, G9 는 초안이 있으면 `source=CUR` 와 `source=DRAFT` 를 모두 읽어 두 응답의 차이로 「새로, 사라짐, 얻음, 잃음」과 초안 열을 그린다(S1). 메뉴 칸은 역할 기준 `searchMenuTree` 와 폴더 없는 `searchRolePerm` 으로, 미리보기는 사람 기준 `searchMenuTree` 로 그린다(S2) |
| 영향 계산 | 초안이 바뀐 뒤 `impact` 를 부른다(최신 요청만 반영). 초안 막대 숫자와 ImpactPanel 이 같은 응답을 쓴다 |
| 사람 ↔ 역할 기준 전환 | 역할 기준에서 사람 기준으로 가면 고른 역할을 받은 첫 사람으로 옮기고 안내 문구를 한 줄 보인다. 받은 사람이 없으면 원래 사람으로 돌아온다 |
| 고르기 연동 | 사람을 고르면 그 사람의 첫 그룹과 첫 역할을 고르고, 역할 칩(GB-003)을 누르면 그 역할이 속한 그룹과 역할을 함께 고른다 |
| 돌아오기 | 3단계 링크로 다른 화면을 다녀오면 `searchBench` 와 현재 보기를 다시 읽는다 |
| 접근성 | 칸 경계는 `role="separator"`, 키보드 ← → 로 20 px 씩(Shift 80 px) 조절한다. 아이콘 버튼은 `aria-label` 과 `title` 에 한글 라벨을 둔다 |

## 10. 스크린샷 / 와이어프레임 참조

| 화면 영역 | 캡처 경로 / 링크 | 출처 | 비고 |
|---|---|---|---|
| 전체 | `docs/perm-bench/mock-v16.html` (브라우저로 연다) | 시안 | 가상 표본. 시안 전용 요소는 분석리포트 §3.4 |

운영 캡처는 없다. 해당 없음. §2.2 와이어프레임과 시안이 기준이다(00 §3.3 캡처 미제공 정책).

시안과 달라진 점은 분석리포트 §8(시안과 정본의 매핑)과 §3.4(시안 전용 요소)에 모았다. 이 문서에서 달라진 점은 아래 세 가지다.

- 초안 막대 숫자는 「얻는 사람, 잃는 사람, 화면」이다(Q-008).
- 메뉴 이름 옆 역할 이니셜 칩은 없다(Q-030).
- 적용 확인, 충돌 안내, 적용 이력 창은 시안에 없어 새로 설계했다.
