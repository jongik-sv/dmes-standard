# MCM — 샘플 공지사항 관리 기능설계서 (예시)

> 템플릿용 축약 예시다. 실제 설계서는
> [`docs/guide/design/templates/기능설계서.template.md`](../../guide/design/templates/기능설계서.template.md)
> 의 §1~11 을 모두 채운다.

## 1. 화면 개요

| 항목 | 값 |
|---|---|
| 화면 ID | SAMPLE-NOTICE-001 |
| 화면명 | 샘플 공지사항 관리 |
| 업무 목적 | 전사 공지사항을 등록·수정·게시 중지한다 |
| 화면 유형 | 목록 + 상세(단일 폼) |

## 2. 화면 영역 정의

| 영역 ID | 영역명 | 설명 |
|---|---|---|
| A-FILTER | 조회조건 | 제목·게시상태·게시기간 |
| A-LIST | 목록 그리드 | 조회 결과 |
| A-DETAIL | 상세 폼 | 선택 건의 내용 편집 |

## 3. 조회조건 정의 (영역: A-FILTER)

| 필드 | 타입 | 필수 | 비고 |
|---|---|---|---|
| 제목 | text | N | 부분 일치 |
| 게시상태 | LoV | N | 전체/게시중/중지 |
| 게시기간 | date range | N | 시작일 ≤ 종료일 |

## 5. 버튼 및 기능 동작 정의

| 버튼 ID | 명칭 | 동작 |
|---|---|---|
| BTN-001 | 조회 | A-FILTER 조건으로 목록 재조회 |
| BTN-002 | 저장 | A-DETAIL 검증 후 등록/수정 |
| BTN-003 | 게시중지 | 게시중 건만 활성 |

## 7. 상태 정의 및 상태별 제어

| 상태 | 설명 | 편집 | 게시중지 |
|---|---|---|---|
| DRAFT | 작성중 | 가능 | 불가 |
| PUBLISHED | 게시중 | 제목만 | 가능 |
| STOPPED | 게시중지 | 불가 | 불가 |

## 11. 특이사항 / 설계 결정

- [확인필요] 게시중지된 공지의 재게시 허용 여부 — 현업 확인 대기.
