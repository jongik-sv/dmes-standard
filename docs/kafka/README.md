# docs/kafka — 메시지 연동(Caravan Hub) 문서

실 프로젝트에서 이 디렉터리는 Kafka 기반 메시지 허브(Caravan Hub)를 통한
시스템 간 연동 문서를 담는다. 크게 두 종류가 섞여 있다.

1. **범용 연동 아키텍처·개발자 매뉴얼** — 전문 포맷 정의, 송수신 호출 규약,
   에러 처리 철학처럼 고객사와 무관하게 재사용되는 내용.
2. **고객사별 이행 계획·DDL** — 특정 레거시 시스템의 EAI 마이그레이션 플랜,
   리네이밍 플랜, 인터페이스 테이블 DDL, Phase 상세설계처럼 프로젝트 고유 내용.

본 템플릿에는 **1번만 남겼다.** 2번(고객사 이행 계획·DDL·스키마 덤프)은 모두 제외했다.
신규 프로젝트에서 이행 계획을 작성할 때는 아래 남겨 둔 매뉴얼과 같은 문서 형식
(30초 요약 → 구성요소 → 절차 → 에러/운영 시나리오)을 따라 이 디렉터리에 추가한다.
