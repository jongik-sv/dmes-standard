# docs/e2e — End-to-End 통합 테스트 설계

실 프로젝트에서 이 디렉터리는 여러 모듈·외부 시스템을 가로지르는 통합 시나리오의
테스트 설계 문서를 담는다. 단위 테스트나 모듈 내 테스트는 각 모듈 코드 옆에 두고,
여기에는 "송신 측에서 발생한 사건이 수신 측 화면까지 도달하는가" 처럼
시스템 경계를 넘는 검증 시나리오만 둔다.

본 템플릿에서는 고객사 연동 시나리오를 제거하고 형식 예시만 남겼다.
