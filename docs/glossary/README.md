# docs/glossary — 용어집·표기 표준

실 프로젝트에서 이 디렉터리는 프로젝트 전체가 공유하는 언어 규약을 담는다.
고객사 용어집(docx/md), 업무 프로세스·용어 정의 문서, 컬럼 명명 표준,
회의록 STT 오인식을 바로잡는 교정 단어집, 이해관계자 명단이 여기에 모인다.

`meeting-minutes` 스킬은 회의록을 정리할 때 이 디렉터리의 교정 단어집과
이해관계자 명단을 근거로 용어·인명을 교정하므로, 신규 프로젝트에서는
착수 초기에 이 두 파일부터 채워야 한다.

본 템플릿에서는 고객사 용어를 모두 제거하고 형식 예시만 남겼다.
