# 샘플 용어집 (예시)

> 템플릿용 예시다. 실제 용어집은 고객사가 실제로 쓰는 표현을 그대로 채집해 채운다.
> 한 용어에 여러 현장 표현이 있으면 "현장 표현" 열에 모두 적고, 문서에서 쓸 표기를 하나로 정한다.

| 표준 용어 | 영문/코드 | 현장 표현 | 정의 |
|---|---|---|---|
| 샘플품목 | SAMPLE_ITEM | 아이템, 자재 | 생산·구매·재고 관리의 최소 식별 단위 |
| 샘플작업지시 | SAMPLE_WORK_ORDER | 지시, 오더 | 특정 품목을 정해진 수량만큼 만들라는 실행 단위 지시 |
| 샘플가용재고 | SAMPLE_AVAILABLE_QTY | 쓸 수 있는 재고 | 현재고에서 이미 예약된 수량을 뺀 잔량 |
| 샘플검사의뢰 | SAMPLE_INSP_REQUEST | 검사 걸기 | 특정 수량에 대해 품질 판정을 요청하는 행위 |
| 샘플공정 | SAMPLE_OPERATION | 공정, 스텝 | 작업지시를 구성하는 순차 작업 단계 |
| 샘플창고 | SAMPLE_WAREHOUSE | 창고, 로케이션 | 재고 수량이 귀속되는 물리적/논리적 보관 위치 |

## 표기 규칙

- 문서 본문에서는 "표준 용어" 열의 표기만 쓴다. 현장 표현은 인용 시에만 병기한다.
- 코드값·컬럼명은 대문자 스네이크 케이스로 통일한다.
