SQL 편집

    
시안 설명 · 실제 화면에서는 shared 공용 부품 SQL 편집기(Monaco) 가 들어갑니다. 구문 강조, 자동 완성, 줄 번호, 찾기·바꾸기, Ctrl/⌘+Enter 시험 실행을 제공합니다. 같은 부품을 예약 작업 관리(실행 SQL·원천 SQL)와 위젯 관리(쿼리 위젯 SQL)에도 적용합니다. Monaco 로더·테마는 shared 한 곳에 두고, 이미 Monaco 를 쓰는 로그 뷰어·DB 뷰어도 같은 로더를 쓰게 맞춥니다.
