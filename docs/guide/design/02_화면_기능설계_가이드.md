## 필수 규칙

- 분석리포트의 항목을 기능설계서로 인용하며 임의 추가하지 않는다.
- Frontend 개발 연계 값은 기능설계서에서 확정하고 디자인/BPMN/개발 체크리스트가 같은 값을 따른다.
- 개발 진입은 [Mes-Guide.md](../MES/Mes-Guide.md) 의 개발 진입 가드를 통과한 뒤 수행한다.
