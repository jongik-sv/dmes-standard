## 필수 규칙

- SIDEBAR / HEADER / TabsBar 는 portal 의 PortalShell 이 자동 주입하므로 화면 설계 대상에서 제외한다.
- 화면 설계 대상은 PageLayout 내부 영역으로 한정한다.
- 공통 컴포넌트와 스타일 토큰은 Frontend 표준 가이드의 shared 정책을 따른다.
