# 한국어 압축 문체 규칙 (LLM용)

- 목적: 토큰 절약. ASD-STE100 원칙 + 명사형 종결 + 조사 생략
- 적용: 스킬 문서, 에이전트 지시문·보고, 레인 메시지, 작업 메모
- 제외: 사람이 읽는 답변·매뉴얼·화면 문구 → `Korean-STE-Writing-Guide.md`
- 등급: 표시 없음 = 권장, [필수] = 반드시

## 1. 종결

- 서술어 → 명사형: `멈춥니다` → `멈춤`, `적용됩니다` → `적용됨`, `확인했습니다` → `확인함`
- 명사로 끝낼 수 있으면 명사: `재기동이 필요합니다` → `재기동 필요`
- 지시 → 대상 + 동작 명사: `MCM을 재기동하세요` → `MCM 재기동`
- 금지 → `~ 금지`: `운영 DB에서 DROP 금지`
- 조건 어미(`~면`, `~때`)는 유지: `실패하면 1회 재시도`
- [필수] 한 문서 안 종결 섞지 않음. 합니다체·해라체 금지

## 2. 조사

- 생략: 주격 `이/가`, 목적격 `을/를`, 명사 사이 `의`, 대조 아닌 `은/는`
  - `설정 파일을 수정합니다` → `설정 파일 수정`
- 행위자가 중요하면 주격 유지: `조정자가 머지 허가`
- 유지: 뜻을 정하는 조사 `에`, `에서`, `으로`, `까지`, `부터`, `만`, `도`, `보다`, 모호한 나열의 `와/과`
  - `L_MAIN에 적용` (`에` 빼면 대상 불명)
- [필수] 생략해서 두 가지로 읽히면 유지
- 명사 4개 넘게 잇지 않음. 넘으면 조사 하나 복원 또는 줄 분리

## 3. 문장·형식

- 한 줄 한 동작. 짧은 불릿 여러 줄
- 조건 먼저: `필수 칸 다 채우면 저장`
- 순서 → 번호 목록 또는 `A → B → C`. 나열 → `·`
- `;`, `—` 금지
- 결론 첫 줄. 인사·맺음말·질문 되풀이 금지
- 근거: 코드 `경로:줄`, 커밋 해시, 전체 명령
- 굵은 글씨·제목 최소

## 4. 어휘

- 기술 용어 원어·음차 그대로: `패스워드`, `cache`, `query`
- [필수] 한 대상 한 단어. 영문·한글 섞어 부르기 금지
- 겹말·번역투·어려운 한자어 금지 → `Korean-STE-Writing-Guide.md` 9절 표
- 모호어(`등`, `기타`, `다소`, `어느 정도`) 대신 항목·수치
- 효과 주장(`안정적`, `원활`) 대신 사실·수치
- 코드·명령·식별자·로그 원문 그대로

## 5. 정보 보존 [필수]

- 숫자·단위·식별자·고유명사·부정 표현 유지
- 확신 수준 유지. 근거 없이 `~일 수 있음` → `~임` 금지
- 원문에 없는 수치·원인·담당자·날짜 생성 금지
- 압축하다 뜻 바뀌면 압축 안 함

## 6. 예

- `MCM을 내리면 모듈의 예약 작업이 멈춥니다.` → `MCM 내리면 모듈 예약 작업 멈춤`
- `칼럼 주석 1,743개가 L_MAIN에 적용되었습니다.` → `칼럼 주석 1,743개 L_MAIN에 적용됨`
- `서버를 내린 뒤 Flyway를 적용하고, 끝나면 서버를 다시 올립니다.` → `1. 서버 내림` `2. Flyway 적용` `3. 서버 재기동`
- `원인은 락 경합일 수 있으나 확인하지 못했습니다.` → `원인 락 경합 추정, 미확인`
