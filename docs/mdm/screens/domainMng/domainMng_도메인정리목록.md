## 3. 검토할 도메인 — N자리 코드 묶음

이름은 업무 용어지만, 실제로는 같은 자리수 코드를 의미와 상관없이 모아 두었다. 의미별로 쪼개거나 일반 코드(156 CD)로 합친다.

| ID | 표준명 | 도메인명 | 길이 | 참조 컬럼 | 문제 |
|---|---|---|---|---|---|
| 157 | TP | 구분 | 1 | 574 | 1자리 컬럼을 모두 묶었다. 구분·등급·상태·방법·유형이 한 도메인이다 |
| 161 | DEF_CD | 부적합 코드 | 3 | 다수 | 3자리 묶음이다. 인도조건(INCOTERMS)·원자재코드도 들어 있다 |
| 162 | FAC_CD | 공장 코드 | 4 | 15 | 4자리 묶음이다. 코터 모드·상차위치·근무지·체인코드도 들어 있다 |

262 PROC_CD_2(2자리 묶음)는 2차에서 지웠다. 그 컬럼 33개는 156 CD 로 옮겨졌다(2.2).

제안: 이름과 맞는 컬럼만 남기고, 나머지 컬럼은 156 CD 아래에 의미별 하위 도메인(예: 인도조건, 유통경로, 상차위치)을 만들어 옮긴다. 다 옮긴 뒤 이름을 실제 의미로 고친다.

## 4. 검토할 도메인 — 자리수·정밀도 변형

같은 의미의 도메인이 자리수·소수 자리만 달라 따로 있다. 기존 도메인의 하위로 넣거나, 기존 도메인의 정의를 넓혀 하나로 합친다.

| ID | 표준명 | 도메인명 | 정의 | 겹치는 도메인 | 참조 |
|---|---|---|---|---|---|
| 246 | HR_TIM | 시 단위 시간 | NUMBER 15,3 h | 67 HOUR (6,0 h) | 컬럼 1 |
| 247 | AREA_DEC | 면적 소수 | NUMBER 13,3 M2 | 239 AREA (10,0 M2) | 컬럼 1 |
| 253 | SPD_DEC | 속도 소수 | NUMBER 5,1 | 224 SPD (5,0 mpm) | 컬럼 0 |
| 256 | FLM_THK_DEC | 필름 두께 소수 | NUMBER 4,1 | 204 FLM_THK (3,0 um) | 컬럼 0 |
| 259 | PH_DEC | pH 소수 | NUMBER 4,2 pH | 223 PH (3,1 pH) | 컬럼 1 |
| 261 | VISCO_DEC | 점도 소수 | NUMBER 5,1 | 238 VISCO (3,0) | 컬럼 3 |

참고: 하위 도메인은 부모보다 길이·소수를 넓힐 수 없다(R06). 그래서 변형을 기존 도메인의 하위로 넣을 수 없었다. 합치려면 기존 도메인의 길이·소수를 넓힌다. 그러면 기존 도메인을 쓰는 컬럼 정의도 같이 넓어지므로, 영향도를 보고 결정한다.

이름에 자리수를 붙였던 263~266 은 2차에서 지웠다(1.1).
