# 컬럼 사전 구성 용어 갱신 (2026-10-02)

용어 사전을 8,152개로 바꾼 뒤([../README.md](../README.md)), 컬럼 7,858개의 구성 용어(`TB_MDM_COLUMN.TERM_IDS`)를 지금 용어로 다시 맞춘 기록이다.

| 파일 | 내용 |
|---|---|
| `Recompose.java` | 서버 분해기 `ColumnNameComposer.forward`(왼쪽부터 최장 일치, I2)로 논리명을 다시 분해해 새 TERM_IDS 를 TSV 로 낸다. DB 는 읽기만 한다. 실행 중인 mdm 서버의 클래스패스로 컴파일·실행했다 |
| `changes.json` | 백업 경로, 바꾼 컬럼 64개의 옛 값·새 값 |

## 규칙

1. 기존 TERM_IDS 의 용어들이 순서대로 논리명을 빈틈없이 덮으면(표기·동의어·별칭 표면형 기준) 기존 값을 그대로 둔다. 표준용어가 들어오며 '지시일'·'자' 같은 용어가 생겨, 분해기만 쓰면 '지시일자'가 '지시 + 일자' 대신 '지시일 + 자'로 잘리기 때문이다.
2. 그렇지 않으면 새 분해 결과를 쓴다. 한 토큰에 후보가 여럿이면 기존 TERM_IDS 에 있던 용어를 먼저 고른다.
3. 매칭 안 된 토큰은 TERM_IDS 에 JSON `null` 로 둔다. 서버(`ColumnMngService`)는 목록의 「구성 용어」와 상세 용어 목록에서 이 자리를 `***` 로 보인다(`ColumnTermPlaceholderTest`). 저장할 때는 기존 규칙(I12)대로 `***` 가 남아 있으면 막는다.
