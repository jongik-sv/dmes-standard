# MDM 용어 유사어 비교 (KURE-v1 INT8, 2026-10-02)

로컬 `src/backend/data/mdm.db` 의 용어 1,485개·컬럼 7,858개를 KURE-v1 INT8 로 인코딩해 유사어를 찾은 기록이다. 모델·풀링·입력 형식은 [term-embedding.md](../term-embedding.md) §2 와 같다(`KURE-v1/int8-1808718e/cls-l2/in1`).

| 파일 | 내용 |
|---|---|
| `encode.py` | 용어·컬럼 인코딩(맥 CPU, 약 5분 40초). 벡터(.npy)는 저장소에 두지 않는다 |
| `verdicts.json` | 용어 쌍 747개와 LLM(sonnet 5) 판정. SAME 6·NEAR 110·BROADER 23·NARROWER 26·DIFFERENT 582 |
| `column_dup_from_same.json` | SAME 용어 하나만 다른 컬럼 쌍(21쌍, 모두 수↔수량) |
| `same_name_dup.json` | 같은 이름·같은 정의로 의미 번호만 나뉜 용어(전압 1~10) |

## 판정 대상을 고른 방법

1. 용어 쌍 중 코사인 0.75 이상(이름이 같은 쌍 제외) 347개.
2. 컬럼 쌍(코사인 0.85 이상) 중 용어 하나만 바뀐 쌍에서, 바뀐 두 용어의 코사인이 0.6 이상인 455개.
3. 둘을 합쳐 747개. 컬럼 임베딩만으로는 상부↔하부·상한↔하한 같은 형제 컬럼이 상위를 차지해 직접 판정하지 않고, 용어 판정 결과에서 컬럼 중복을 끌어냈다.

## 적용

판정 결과는 아직 사전에 반영하지 않았다. SAME 은 합칠지, NEAR 는 SYNONYMS 에 서로 적을지 사람이 정한 뒤 반영한다.

## 2차 비교: 용어 8,152개 (2026-10-02, D-137 병합 뒤)

표준용어·용어집 병합([dict-std](../dict-std/README.md)) 뒤 용어가 8,152개가 되어 다시 비교했다. 위 1차 결과(`verdicts.json` 등)는 1,485개 기준이라 참고용으로만 남긴다.

| 파일 | 내용 |
|---|---|
| `pairs_v2.py` | 후보 쌍 추출(비교 전용 인코딩 약 2분) |
| `verdicts_v2.json` | 쌍 1,561개와 LLM(sonnet 5, 6개로 나눔) 판정. SAME 650·NEAR 485·DIFFERENT 329·BROADER 56·NARROWER 41 |
| `same_groups_v2.json` | SAME 쌍을 이은 묶음 507개(2개 408·3개 77·4개 22) |
| `similarity_v2.xlsx` | 검토용. 「판정」 시트(전체 쌍), 「SAME 묶음」 시트(기존 용어가 2개 이상인 27묶음은 노란색) |

- **비교 입력:** 사전의 EMBEDDING 은 정의를 포함해서, 정의 없는 표준용어와 정의 있는 기존 용어 사이의 코사인이 낮게 나온다(0.8 이상 8쌍). 그래서 비교에는 모든 용어를 `{표기} ({영문명})` 으로 다시 인코딩한 벡터를 썼다. 이 벡터는 사전에 저장하지 않는다.
- **쌍 기준:** 이름이 같은 쌍은 뺐다. 출처가 다른 쌍은 0.82 이상, 기존끼리·용어집끼리는 0.85 이상, 표준용어끼리는 0.90 이상이다.
- **SAME 출처 조합:** 기존↔표준용어 534, 표준용어끼리 94, 용어집↔표준용어 11, 용어집↔기존 6, 기존끼리 4, 용어집끼리 1.
- **기존끼리 SAME 4쌍 중 둘 다 컬럼이 쓰는 쌍:** 스팡글/스팽글, 인터마/인터메시, 년도/연도. 컬럼 사전 안의 실제 중복이다.
- **판정 이유:** 이번 판정의 reason 은 판정별 공통 문장이라 쌍마다 근거를 담지 않는다. 묶음은 SAME 을 이어 만든 것이라, 중간 쌍을 거쳐 다른 기존 용어가 한 묶음에 들어갈 수 있다(예: 구분·유형이 Type 을 거쳐 묶임). 노란 27묶음은 사람이 확인한다.
- **적용:** 아직 사전에 반영하지 않았다. SAME 은 표준용어 쪽을 기존 용어의 동의어로 옮기고 지울지, NEAR 는 SYNONYMS 에 서로 적을지 사람이 정한 뒤 반영한다.
