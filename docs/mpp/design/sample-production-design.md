# MPP — 샘플 생산실적 등록 기능설계서 (예시)

> 템플릿용 축약 예시다. 실제 설계서는
> [`docs/guide/design/templates/기능설계서.template.md`](../../guide/design/templates/기능설계서.template.md) 를 따른다.

## 1. 화면 개요

| 항목 | 값 |
|---|---|
| 화면 ID | SAMPLE-PROD-001 |
| 화면명 | 샘플 생산실적 등록 |
| 업무 목적 | 작업지시에 대한 생산 수량(양품·불량)을 등록한다 |
| 화면 유형 | 목록 + 실적 입력 폼 |

## 2. 화면 영역 정의

| 영역 ID | 영역명 | 설명 |
|---|---|---|
| A-FILTER | 조회조건 | 작업지시번호·설비·실적일자 |
| A-LIST | 작업지시 목록 | 진행 중 지시 |
| A-DETAIL | 실적 입력 | 양품수량·불량수량·불량사유 |

## 5. 버튼 및 기능 동작 정의

| 버튼 ID | 명칭 | 동작 |
|---|---|---|
| BTN-001 | 조회 | 조건에 맞는 작업지시 조회 |
| BTN-002 | 실적저장 | 수량 검증 후 실적 등록 |
| BTN-003 | 실적취소 | 당일 등록 건만 활성 |

## 6. 입력값 검증 규칙

- 양품수량 + 불량수량 ≤ 잔여 지시수량.
- 불량수량 > 0 이면 불량사유 필수.

## 7. 상태 정의 및 상태별 제어

| 상태 | 설명 | 실적저장 | 실적취소 |
|---|---|---|---|
| RELEASED | 지시발행 | 가능 | 불가 |
| IN_PROGRESS | 생산중 | 가능 | 가능 |
| CLOSED | 지시마감 | 불가 | 불가 |
