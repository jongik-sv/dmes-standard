# docs/mpp — 생산실적(MPP) 모듈 문서

실 프로젝트에서 이 디렉터리는 생산 수행·실적 모듈의 문서를 담는다.
현재는 화면 설계 문서를 모으는 `design/` 만 두는 얇은 구성이며,
모듈이 커지면 `screens/`·`analysis/` 등을 MLS·MQC 와 같은 형태로 추가한다.

본 템플릿에서는 고객사 설계 내용을 제거하고
생산실적 화면 설계서 형식을 보여 주는 샘플 1건만 남겼다.
