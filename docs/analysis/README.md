# docs/analysis — 프로젝트 횡단 분석 보고서

실 프로젝트에서 이 디렉터리는 특정 모듈에 속하지 않는 분석 보고서를 담는다.
AI 도구 활용 효과 분석 같은 내부 보고용 문서, 레거시 시스템 기능 분해 분석,
접근 권한 관리 체계 분석, 업무 프로세스 재설계 검토 문서가 여기에 모인다.
모듈 설계 결정으로 굳어지면 해당 모듈의 ADR 로 옮긴다.

본 템플릿에서는 고객사 분석 내용을 모두 제거하고 형식 예시만 남겼다.
