# 샘플 분석 보고서 — 레거시 화면 기능 분해 (예시)

> 템플릿용 1페이지 뼈대다. 실제 보고서는 대상·근거·수치를 실측으로 채운다.

## 1. 분석 목적

레거시 시스템의 화면들이 신규 시스템의 어느 모듈에 귀속되어야 하는지 판단 근거를 만든다.

## 2. 분석 대상과 방법

| 항목 | 내용 |
|---|---|
| 대상 | 샘플 영역 화면 N건 |
| 근거 | 레거시 소스 덤프(`docs/external/SampleErp/`) 직접 카운트 |
| 방법 | 화면별 BPA 작성 후 §2 업무 목적 기준으로 분류 |

## 3. 분석 결과

| 분류 | 건수 | 판단 근거 |
|---|---|---|
| 신규 시스템 이관 | - | 생산 실행과 직접 연결됨 |
| 레거시 존치 | - | 회계·인사 등 범위 밖 |
| 판단 보류 | - | 업무 소유 부서 미확정 |

## 4. 시사점

- 판단 보류 건은 소유 부서 확정 전까지 범위 산정에서 제외한다.
- 이관 대상 중 조회 전용 화면은 별도 우선순위로 후행 배치한다.

## 5. 후속 조치

| 조치 | 담당 | 기한 |
|---|---|---|
| 보류 건 소유 부서 확인 | - | - |
| 이관 대상 우선순위 확정 | - | - |
