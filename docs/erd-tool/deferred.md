# DB 설계 도구(ERD) 미룬 기능 목록

- 작성일: 2026-10-10
- 관련 문서: [구상](../superpowers/specs/2026-10-09-erd-tool-concept.md), [연구 보고서](2026-10-09-erd-tool-research.md)
- 첫 스펙 범위는 **기반 + P1(가져오기·뷰어) + P2(exERD 방식 편집)** 이다. 이 범위에 넣지 않은 기능을 모두 여기에 적는다.
- 항목을 다시 꺼낼 때는 "근거" 칸의 문서 절부터 읽는다. 항목을 구현하면 이 문서에서 지우지 말고 "처리" 칸에 커밋을 적는다.
