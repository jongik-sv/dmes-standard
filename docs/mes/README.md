# docs/mes — MES 전체 제안·설계 문서

실 프로젝트에서 이 디렉터리는 개별 모듈에 속하지 않는 MES 전체 수준의 문서를 담는다.
사업 제안서 분석 문서, 전체 테이블 설계 문서(md/xlsx/docx 여러 개정판),
모듈 경계와 범위를 정리한 문서가 여기에 모인다. 개정이 반복되므로 파일명에 버전을 붙인다.

본 템플릿에서는 고객사 제안 내용과 테이블 설계를 모두 제거하고,
모듈 제안서 형식을 보여 주는 샘플 1건만 남겼다.
