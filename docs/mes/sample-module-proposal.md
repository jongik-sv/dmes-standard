# 샘플 모듈 제안서 (예시)

> 템플릿용 1페이지 뼈대다. 실제 제안서는 고객사 요구사항·범위 협의 결과를 반영해 작성한다.

## 1. 배경

현행 레거시 시스템은 생산 실적을 수기 집계에 의존하여 집계 시점과 실제 작업 시점 사이에
지연이 발생한다. 이로 인해 계획 재수립이 하루 단위로만 가능하다.

## 2. 제안 범위

| 구분 | 포함 | 제외 |
|---|---|---|
| 기준정보 | 품목·설비·창고 | 인사·회계 마스터 |
| 실행 | 작업지시 발행, 실적 등록 | 설비 자동 인터페이스 |
| 조회 | 재고·실적 현황 | 경영 대시보드 |

## 3. 목표 효과

- 실적 반영 지연을 일 단위에서 시간 단위로 단축.
- 재고 수불 근거를 시스템 이력으로 일원화.

## 4. 단계 계획

| 단계 | 내용 | 기간(예시) |
|---|---|---|
| 1단계 | 기준정보·권한 이행 | M+0 ~ M+2 |
| 2단계 | 실행 화면 구축 | M+2 ~ M+5 |
| 3단계 | 병행 운영·안정화 | M+5 ~ M+6 |

## 5. 전제 및 제약

- 레거시 시스템의 마스터 데이터가 정본이며, 신규 시스템은 수신 측이다.
- 설비 연동은 별도 과제로 분리한다.

## 6. 미결 사항

- [확인필요] 병행 운영 기간 중 정본 시스템을 어느 쪽으로 둘 것인지.
