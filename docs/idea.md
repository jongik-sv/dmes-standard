## 필요기능

### 담당자 알림기능

- 프로그램에서 발생한 기능
- 메일과 연관 기능
- 알림의 중요도 고려
- 메시지 발송 그룹 관리 기능
- 사용자 관리에서 사용되는 부서코드를 MDM의 마스터코드로 변경 (TB_MCM_DEPT_INFO와 마스터코드 선택가능하도록)
- 비밀번호도 도메인으로 관리 하자.
- 시스템의 이름을 정할 수 있는 기능(MDM, MES, ...)

### 기타 수정

- RULE이 상속관계를 가지도록 수정
- 룰도  major, minor 버전으로 처리 되도록 변경하자.
- 마루 MDM 만들때 따로 만든 컴포넌트가 있는지 확인하고 있으면 공통으로 올리자.
- 각 화면에 대해 전체 화면으로 보기 기능 추가.
- 같은 화면 중복으로 열기 (서로 다른 내용을 보기 위해)



### MDM 관련 라이브러리 수정

- 현재 MDM 내용을 실제 내용으로 넣기
- MDM 내용에 대한 캐시관리 (제일 먼저 처리 되어야함)
  - 캐시 등록
  - 캐시 삭제 / 재등록
- 캡션/라벨을 MDM에서 자동으로 가져옴
- 룰 엔진 실행 검증
  - 화면 값 자동 검증
  - BE 에서 값 검증 및 체크
  - 특정 화면의 자체 컬럼에 대한 룰엔진(예를 들어 이 화면에서는 이 값이 NOT NULL)
  - 화면에만 있는 비즈니스 룰 자체에 대한 AST 생성/캐시 기능
  - AST를 이용한 값 TEST 시 같은 OP, 오퍼랜드 세트는 한 번만  TEST 하도록 하면 빠르겠다.

### MDM 화면

- 룰 세트 편집을 비주얼하게 바꾸자.  각 룰들은 태스크로 나오고 분기 태스크도 넣을 수 있다. 반복도 필요하면 넣는다.
  - BPMN 에디터를 쓸 것인가? 아니면 관련 컴포넌트를 사용할 것인가? 아니면 새로 만들 것인가?
  - 테스트를 넣으면 실제 비주얼한 오브젝트 에디터에서 실제 처리된 내용을 볼 수 있으면 좋겠다.
  - (완료 2026-10-01, D-124) 룰 세트 디버거: 중단점에서 변수 값을 고쳐 이어 실행 — 처음부터 다시 실행하며 고친 값을 끼워 넣는 방식
- 마스터코드
  - 마루 코드 / 마루 코드 수정 하나의 화면으로
  - 마루 코드 삭제 없음
  - 코드 편집 / 카테고리 편집은 하나의 화면으로
  - 마루 코드에서 코드편집 버튼을 누르면 코드 편집 / 카테고리 편집 화면으로 이동
- 마스터데이터 : 위의 마스터코드와 같은 기준으로 변경
  - 마스터데이터 편집은? 또는 조회는?
- 새버전, 확정이동, 삭제, 확정취소, 해제, ... 넘기기 --&gt; 새 버전(major), 새 버전(minor), 삭제, 확정(이동이라는 말 삭제), 확정취소, 삭제, 해제, ...넘기기
- 찾기 누르면 너무 어색하다. 이것도 수정하자.
- (완료 2026-10-01) 룰 세트 편집 화면 최적화 수행 — 캔버스 다시 그리기·dagre 캐시(713b552a), 서버 쿼리 감소(5c8aded5)
- 도메인에서 부모 연결 및 연결제거
- 룰 세트 편집화면에서 글자 버튼을 아이콘 버튼으로 변경하고 2줄로 되어 있는 것을 한줄로 바꾸자.
