# 13. 멀티 데이터소스 라우팅 (미개발)

> 통합 원본: `new/06-data-layer.md` (`상태: 설계 단계`)
> 구현 상태: **미구현** (멀티 DataSource). 단, MyBatis 인터셉터(SqlLogger, AuditInterceptor) 는 구현됨 → 정리본 06 참고.

---

## 1. 설계 의도

- 모듈별 또는 도메인별 별도 DataSource 운영
- 읽기/쓰기 분리 (master/replica)
- DataSource 라우팅 추상화로 도메인 코드 변경 최소화

---

## 2. 제안 명세

### 2.1 패키지
```
cactus-core/datasource/
├── DataSourceAutoConfiguration.java
├── DataSourceProperties.java
├── DataSourceRouter.java                # AbstractRoutingDataSource
├── DataSourceContextHolder.java         # ThreadLocal datasource key
└── annotation/
    ├── ReadOnly.java                    # @ReadOnly → replica 라우팅
    └── DataSource.java                  # @DataSource("master") 등
```

### 2.2 라우팅 패턴
```java
@DataSource("portal-master")
public List<User> findUsers() { ... }

@ReadOnly
@DataSource("portal-replica")
public List<User> searchUsers() { ... }
```

AOP 또는 transactional advice 로 ThreadLocal 에 datasource key 주입 → AbstractRoutingDataSource 가 분기.

### 2.3 application.yml
```yaml
cactus:
  datasource:
    portal-master:
      jdbc-url: jdbc:postgresql://...
    portal-replica:
      jdbc-url: jdbc:postgresql://replica...
    mpp-master:
      jdbc-url: jdbc:sqlserver://...
```

### 2.4 PaginationInterceptor (MyBatis)
- 모든 SELECT 에 LIMIT/OFFSET 자동 주입
- Spring Data JPA 의 Pageable 과 동등한 인터페이스

---

## 3. 미구현 사유

- 현 단계: 모듈별 단일 DataSource (portal/mpp 각각 별도 WAS + 별도 DB)
- 모듈간 분리는 이미 WAS 레벨에서 달성 → 한 모듈 내 멀티 DS 요구 미발생
- 읽기/쓰기 분리는 트래픽 임계 도달 후 검토

---

## 4. 부분 구현 흔적

| 구분 | 위치 | 내용 |
|---|---|---|
| MyBatis 감사 인터셉터 | `cactus-core/audit/CactusMybatisAuditInterceptor.java` | 06번 정리본 |
| SQL 로거 | `cactus-core/audit/SqlLoggingInterceptor.java` | 06번 정리본 |
| MyBatis AutoConfig | `cactus-core/audit/AuditAutoConfiguration.java` (`@ConditionalOnClass(SqlSessionFactory.class)`) | 06번 정리본 |

→ MyBatis 인프라 일부는 구현되어 있어, 멀티 DS 도입 시 그 위에 PaginationInterceptor 등을 추가하면 됨.

---

## 5. 도입 시 고려사항

| 항목 | 설명 |
|---|---|
| 트랜잭션 경계 | 읽기/쓰기 분리 시 트랜잭션이 read-only replica 에 routed 되지 않도록 주의 |
| 캐시 일관성 | master 에 commit 후 replica 지연 → stale read 가능 |
| 헬스체크 | replica 장애 시 master 로 자동 폴백 |
| MyBatis 인터셉터 | 인터셉터 등록 순서 (SqlLogger → AuditInterceptor → Pagination) 정의 필요 |

---

## 6. 임시 대안

- 모듈별 별도 WAS + DB 인프라 분리 유지 (현재 상태)
- 한 모듈 내 멀티 DS 필요 시 도입 검토
