# Cactus 프로젝트 모듈 설계

> 일시: 2026-03-20 (원본) / 2026-04-26 (현행 사실 박스)
> 목적: cactus 멀티 모듈 구조 및 cactus-oasis 상세 설계
>
> **현행 사실 (마이그레이션 완료, 2026-04-26)**
> - 패키지: 본문 트리의 `com/dongkuk/cactus/...` 경로는 현행 `com/dongkuk/dmes/cactus/...` 로 읽는다. group `com.dongkuk` → `com.dongkuk.dmes`.
> - 멀티 모듈 구조 변경: 옛 `cactus/{cactus-core, cactus-oasis}` 멀티 모듈 분리는 **폐기되었다.** 현행은 cactus-core **단일 라이브러리 모듈**이며, OASIS 통합 클래스(`OasisController`, `OasisServiceExecutor`, `OasisAutoConfiguration` 등)는 cactus-core 내부의 `com.dongkuk.dmes.cactus.oasis` 패키지로 흡수되었다.
> - AutoConfiguration imports: `CactusAutoConfiguration`, `SecurityAutoConfiguration`, `CactusAuthAutoConfiguration`, `CactusWebSecurityAutoConfiguration`, `AuditAutoConfiguration`, `OasisAutoConfiguration`.
> - 본 문서의 멀티 모듈 분리 의도(서비스 그룹별 의존성 격리)는 의사결정 맥락 보존을 위해 본문 그대로 둔다. 실제 코드는 단일 모듈로 운영된다.

## 1. 멀티 모듈 구성

```
cactus/                              ← 루트 프로젝트
├── settings.gradle                  ← include 'cactus-core', 'cactus-oasis'
├── build.gradle                     ← 공통 설정 (Java 21, 인코딩 등)
│
├── cactus-core/                     ← 항상 사용하는 공통 모듈
│   ├── build.gradle
│   └── src/main/java/com/dongkuk/cactus/
│       ├── common/
│       │   ├── ApiResponse.java          ← 단순 REST API 응답 래퍼
│       │   ├── CactusRequest.java         ← MES 화면 요청 포맷
│       │   ├── CactusResponse.java        ← MES 화면 응답 포맷
│       │   ├── GridData.java             ← 요청용 그리드 (rows)
│       │   ├── GridResult.java           ← 응답용 그리드 (rows + columns optional)
│       │   ├── ColumnMeta.java           ← 컬럼 메타 (optional)
│       │   ├── ErrorDetail.java          ← 행/필드 단위 에러
│       │   ├── RowStatus.java            ← enum (C, U, D, R)
│       │   ├── ErrorCode.java            ← 에러 코드 enum
│       │   └── BusinessException.java    ← 비즈니스 예외
│       ├── file/
│       │   ├── FileController.java       ← 첨부파일 업로드/다운로드 (/api/file/*)
│       │   └── FileService.java          ← 첨부파일 처리 로직
│       ├── excel/
│       │   ├── ExcelController.java      ← 엑셀 업로드/다운로드 (/api/excel/*)
│       │   └── ExcelService.java         ← 엑셀 파싱/생성 로직
│       ├── security/                     ← JWT, 인증
│       └── autoconfigure/                ← Spring Boot 자동설정
│
└── cactus-oasis/                    ← oasis 연동 시에만 사용하는 모듈
    ├── build.gradle                 ← depends on cactus-core + oasis-core(4.x)
    └── src/main/java/com/dongkuk/cactus/oasis/
        ├── OasisController.java          ← 공통 컨트롤러 (/api/{serviceGroup}/{serviceId}/{action})
        ├── CactusRequestConverter.java    ← CactusRequest → ServiceContext 변환
        ├── CactusResponseConverter.java   ← ServiceResult → CactusResponse 변환
        ├── OasisServiceExecutor.java     ← ServiceStarter 래핑, 서비스 실행 담당
        ├── OasisAutoConfiguration.java   ← 자동설정 (ServiceStarter, 컨트롤러 빈 등록)
        └── OasisProperties.java          ← 설정 프로퍼티 (서비스 경로 등)
```

## 2. 모듈별 역할

| 모듈 | 역할 | 핵심 내용 |
|------|------|----------|
| `cactus-core` | 데이터 포맷 + 인증 + 파일/엑셀 + 공통 유틸 | `CactusRequest`, `CactusResponse`, `ApiResponse<T>`, Security/JWT, Excel/File |
| `cactus-oasis` | oasis-core 연동 + 공통 컨트롤러 | URL 라우팅 → oasis Context 변환 → 서비스 실행 → 응답 변환 |

## 3. 업무 프로젝트 사용법

```groovy

}
// → 업무 개발자가 컨트롤러에서 @RequestBody CactusRequest로 받아서 직접 처리
```

## 5. cactus-oasis 모듈 상세 설계

> oasis 4.x (ServiceStarter, ServiceContext, ServiceResult, TypedObject) 기반
> 참조: oasis 4.x 소스 (`D:\dmes-fwk\workspace-oasis\oasis`), ksm 샘플 (`D:\dmes-fwk\workspace-oasis\ksm`)

### 5.1 oasis 4.x 핵심 클래스

| 클래스 | 역할 |
|--------|------|
| `ServiceStarter` | 서비스 실행 진입점. `start(serviceId, serviceContext)` |
| `ServiceContext` / `DefaultServiceContext` | 파라미터를 `Map<String, TypedObject>`로 보관 |
| `ServiceResult` | 실행 결과. `serviceResultCode()`, `result(key)`, `results()` |
| `ServiceResultCode` | `SUCCESS`, `USER_ERROR`, `SYSTEM_ERROR` |
| `TypedObject` | 모든 값을 감싸는 타입 래퍼 |
| `ApplicationContext` / `SpringApplicationContext` | Spring 빈을 oasis에 주입 |
| `NonTransactionalServiceStarterFactory` | ServiceStarter 팩토리 (비트랜잭션) |

### 5.2 변환 흐름

```
[프론트엔드]
    │
    │  POST /api/{serviceGroup}/{serviceId}/{action}
    │  Body: CactusRequest (JSON)
    ▼
[OasisController]
    │
    │  @RequestBody CactusRequest
    ▼
[CactusRequestConverter]
    │
    │  CactusRequest → Map<String, TypedObject>
    │
    │  변환 규칙:
    │  ├── meta.userId    → TypedObject("user01")
    │  ├── meta.menuId    → TypedObject("PROD001")
    │  ├── params.*         → TypedObject(각 값)
    │  ├── grids.*          → TypedObject(GridData)
    │  └── action (PathVar) → TypedObject("search")
    ▼
[OasisServiceExecutor]
    │
    │  ServiceContext sc = new DefaultServiceContext(appCtx, typedObjectMap);
    │  ServiceResult result = serviceStarter.start(serviceId, sc);
    ▼
[CactusResponseConverter]
    │
    │  ServiceResult → CactusResponse
    │
    │  변환 규칙:
    │  ├── serviceResultCode == SUCCESS
    │  │   → meta.success = true, code = "0000"
    │  │   → results() 중 List<Map> 타입 → grids.{key}.rows
    │  │   → results() 중 단일 값 → params.{key}
    │  │
    │  ├── serviceResultCode == USER_ERROR
    │  │   → meta.success = false
    │  │   → serviceResultMessage → meta.message
    │  │
    │  └── serviceResultCode == SYSTEM_ERROR
    │      → meta.success = false, code = "S001"
    ▼
[프론트엔드]
    CactusResponse (JSON)
```

### 5.3 클래스별 상세 설계

#### OasisController.java

```java
@RestController
@RequestMapping("/api")
public class OasisController {

    private final OasisServiceExecutor executor;

    @PostMapping("/{serviceGroup}/{serviceId}/{action}")
    public CactusResponse handle(
            @RequestBody CactusRequest request,
            @PathVariable String serviceGroup,
            @PathVariable String serviceId,
            @PathVariable String action) {

        return executor.execute(serviceId, action, request);
    }
}
```

- URL 패턴: `/api/{serviceGroup}/{serviceId}/{action}`
- `serviceGroup`은 논리적 분류 (라우팅에는 미사용, 로깅/감사용)
- `serviceId`는 BPMN 프로세스 ID와 매핑
- `action`은 ServiceContext에 전달 → BPMN 게이트웨이에서 분기

#### CactusRequestConverter.java

```java
public class CactusRequestConverter {

    /**
     * CactusRequest → Map<String, TypedObject> 변환
     */
    public Map<String, TypedObject> convert(CactusRequest request, String action) {
        Map<String, TypedObject> map = new HashMap<>();

        // action
        map.put("action", new TypedObject(action));

        // meta 정보
        RequestMeta meta = request.getMeta();
        map.put("userId", new TypedObject(meta.getUserId()));
        map.put("menuId", new TypedObject(meta.getMenuId()));

        // params → 각각 TypedObject로
        if (request.getParams() != null) {
            request.getParams().forEach((key, value) ->
                map.put(key, new TypedObject(value))
            );
        }

        // grids → 그리드별로 TypedObject로
        if (request.getGrids() != null) {
            request.getGrids().forEach((key, gridData) ->
                map.put(key, new TypedObject(gridData.getRows()))
            );
        }

        return map;
    }
}
```

#### CactusResponseConverter.java

```java
public class CactusResponseConverter {

    /**
     * ServiceResult → CactusResponse 변환
     */
    public CactusResponse convert(ServiceResult result, String txId) {
        if (result.serviceResultCode() == ServiceResultCode.SUCCESS) {
            return convertSuccess(result, txId);
        } else {
            return convertError(result, txId);
        }
    }

    private CactusResponse convertSuccess(ServiceResult result, String txId) {
        Map<String, Object> params = new HashMap<>();
        Map<String, GridResult> grids = new HashMap<>();

        // ServiceResult의 results를 타입별로 분류
        result.results().forEach((key, typedObject) -> {
            Object value = typedObject.getObject();
            if (value instanceof List) {
                // List<Map> → grids
                grids.put(key, new GridResult(null, (List<Map<String, Object>>) value));
            } else {
                // 단일 값 → params
                params.put(key, value);
            }
        });

        return CactusResponse.builder()
                .meta(ResponseMeta.success(txId))
                .params(params)
                .grids(grids.isEmpty() ? null : grids)
                .build();
    }

    private CactusResponse convertError(ServiceResult result, String txId) {
        String code = result.serviceResultCode() == ServiceResultCode.USER_ERROR ? "E001" : "S001";
        return CactusResponse.builder()
                .meta(ResponseMeta.error(txId, code, result.serviceResultMessage()))
                .build();
    }
}
```

#### OasisServiceExecutor.java

```java
public class OasisServiceExecutor {

    private final ServiceStarter serviceStarter;
    private final ApplicationContext springApplicationContext;
    private final CactusRequestConverter requestConverter;
    private final CactusResponseConverter responseConverter;

    public CactusResponse execute(String serviceId, String action, CactusRequest request) {
        String txId = TxIdGenerator.generate(reqHeader.getUserId(), reqHeader.getMenuId());

        try {
            // 1. CactusRequest → TypedObject Map
            Map<String, TypedObject> inputs = requestConverter.convert(request, action);

            // 2. ServiceContext 생성 (Spring 빈 접근 가능)
            com.dongkuk.oasis.context.ApplicationContext oasisAppCtx =
                    new SpringApplicationContext(springApplicationContext);
            ServiceContext sc = new DefaultServiceContext(oasisAppCtx, inputs);

            // 3. 서비스 실행
            ServiceResult result = serviceStarter.start(serviceId, sc);

            // 4. ServiceResult → CactusResponse
            return responseConverter.convert(result, txId);

        } catch (Exception e) {
            return CactusResponse.builder()
                    .meta(ResponseMeta.error(txId, "S999", e.getMessage()))
                    .build();
        }
    }
}
```

#### OasisAutoConfiguration.java

```java
@Configuration
@ConditionalOnClass(ServiceStarter.class)
public class OasisAutoConfiguration {

    @Bean
    @ConditionalOnMissingBean
    public ServiceStarter serviceStarter() {
        return new NonTransactionalServiceStarterFactory().generateServiceStarter();
    }

    @Bean
    public CactusRequestConverter oasisRequestConverter() {
        return new CactusRequestConverter();
    }

    @Bean
    public CactusResponseConverter oasisResponseConverter() {
        return new CactusResponseConverter();
    }

    @Bean
    public OasisServiceExecutor oasisServiceExecutor(
            ServiceStarter serviceStarter,
            ApplicationContext springApplicationContext,
            CactusRequestConverter requestConverter,
            CactusResponseConverter responseConverter) {
        return new OasisServiceExecutor(
                serviceStarter, springApplicationContext,
                requestConverter, responseConverter);
    }

    @Bean
    public OasisController oasisController(OasisServiceExecutor executor) {
        return new OasisController(executor);
    }
}
```

- `@ConditionalOnClass(ServiceStarter.class)` — oasis-core가 classpath에 있을 때만 활성화
- `@ConditionalOnMissingBean` — 업무 프로젝트에서 커스텀 ServiceStarter를 등록하면 그것을 사용

### 5.5 업무 프로젝트에서의 사용 예시

업무 개발자는 **컨트롤러를 만들지 않고**, BPMN 서비스 정의 + Java 서비스 클래스만 작성한다.

```
업무 프로젝트/
├── build.gradle                         ← cactus-core + cactus-oasis 의존
├── src/main/java/.../
│   └── service/
│       └── ProdResultService.java       ← 순수 Java 비즈니스 로직
└── src/main/resources/
    └── services/
        └── prodResult.bpmn              ← 서비스 흐름 정의
```

```java
// 업무 서비스 클래스 — oasis 프레임워크가 BPMN에서 호출
public class ProdResultService {

    public List<Map<String, Object>> search(String plantCd, String fromDate, String toDate) {
        // DB 조회 후 결과 반환
    }

    public int save(List<Map<String, Object>> master, List<Map<String, Object>> detail) {
        // rowStatus 기반 CUD 처리
        return savedCount;
    }
}
```

```
프론트 호출:
POST /api/prod/prodResult/search
Body: { meta: {...}, params: { plantCd: "P01", fromDate: "2026-03-01" } }

→ OasisController 수신
→ CactusRequestConverter가 TypedObject Map 변환
→ serviceStarter.start("prodResult", serviceContext)
→ BPMN 게이트웨이에서 action="search" 분기
→ ProdResultService.search() 실행
→ ServiceResult 반환
→ CactusResponseConverter가 CactusResponse로 변환
→ JSON 응답
```
