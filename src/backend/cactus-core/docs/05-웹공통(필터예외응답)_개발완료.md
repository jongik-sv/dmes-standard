## 1. 필터 체인

`CactusWebSecurityAutoConfiguration` 가 SecurityFilterChain 에 명시 등록 (servlet 컨테이너 자동 등록은 `setEnabled(false)` 로 차단):

```
HTTP 요청
  ↓ TxIdFilter            (OASIS MDCTemplate 기반, service_tag + 임시 txId)
  ↓ RequestIdFilter       (X-Request-Id 처리)
  ↓ ClientKeyFilter       (cactus-core 자체 — `cactus.security.client-key` 정의 시 활성)
  ↓ JwtAuthenticationFilter (Bearer 추출 + SecurityContext + UserContextHolder + JwtTokenHolder)
  ↓ Spring Security UsernamePasswordAuthenticationFilter
  ↓ Controller
```

> `@Order` 어노테이션은 부착하지 않음 — SecurityFilterChain 명시 등록 시 servlet 표준 `@Order` 는 무의미하므로 제거됨 (정리본 08 참고).

## 2. TxIdFilter

| 항목 | 내용 |
|---|---|
| 위치 | `cactus-core/web/filter/TxIdFilter.java` |
| 역할 | OASIS `MDCTemplate` 으로 요청을 감싸서 service_tag(4자리) 자동 설정 + 임시 UUID 8자리를 MDC `txId` 에 설정. OasisServiceExecutor 가 정식 txId 로 교체. |
| 로그 패턴 | `[%X{txId}] message...` (logback-spring.xml) |
| 의존 | `oasis-core` 의 `MDCTemplate` |

`RequestIdFilter` 는 별도 필터로 X-Request-Id 헤더를 처리. 자세한 흐름은 정리본 08 참고.

## 3. GlobalExceptionHandler

| 항목 | 내용 |
|---|---|
| 위치 | `cactus-core/web/exception/GlobalExceptionHandler.java` |
| 어노테이션 | `@RestControllerAdvice` |
| 처리 예외 | `BusinessException`, `Exception`, `MethodArgumentNotValidException`, `AccessDeniedException` 등 |
| 응답 | `CactusResponse` (meta.success=false, errors 포함) |

OasisController 내부 예외는 OasisServiceExecutor 가 1차 처리하므로, 본 핸들러는 그 외 진입 경로(필터·기타 컨트롤러)의 예외를 잡는 안전망 역할.

## 4. BusinessException + ErrorCode

### 4.1 BusinessException
```java
throw new BusinessException(ErrorCode.REQUIRED_VALUE, "사용자 메시지", errorDetailList);
```

| 필드 | 의미 |
|---|---|
| `errorCode` | ErrorCode enum |
| `message` | 사용자 메시지 |
| `errors` | List<ErrorDetail> (그리드/필드 단위 상세) |

### 4.2 ErrorCode (enum 전체)

분류 체계: **E0xx** 비즈니스 (400) / **A0xx** 인증·권한 (401·403) / **S0xx** 시스템 (500)

| 코드 | HTTP | 이름 | 기본 메시지 |
|---|---|---|---|
| `E001` | 400 | REQUIRED_VALUE | 필수값이 누락되었습니다 |
| `E002` | 400 | INVALID_VALUE | 유효하지 않은 값입니다 |
| `E003` | 400 | DUPLICATE_DATA | 중복 데이터가 존재합니다 |
| `E010` | 400 | BUSINESS_ERROR | 비즈니스 규칙 위반입니다 |
| `A004` | 401 | AUTH_FAILED | 사용자 ID 또는 비밀번호가 일치하지 않습니다 |
| `A005` | 403 | ACCOUNT_LOCKED | 계정이 잠겼습니다. 관리자에게 문의하세요 |
| `A006` | 403 | ACCOUNT_DISABLED | 비활성 계정입니다 |
| `A008` | 401 | TOKEN_EXPIRED | 토큰이 만료되었습니다 |
| `A009` | 401 | INVALID_TOKEN | 유효하지 않은 토큰입니다 |
| `A010` | 403 | ACCESS_DENIED | 접근 권한이 없습니다 |
| `S001` | 500 | INTERNAL_ERROR | 서버 내부 오류가 발생했습니다 |
| `S002` | 500 | DB_ERROR | 데이터베이스 연결 오류입니다 |
| `S003` | 500 | SERVICE_EXECUTION_ERROR | 서비스 실행 중 오류가 발생했습니다 |
| `S999` | 500 | UNKNOWN_ERROR | 알 수 없는 오류가 발생했습니다 |

소스: `cactus-core/common/ErrorCode.java`

## 5. ErrorDetail

`cactus-core/web/response/ErrorDetail.java` (record).

```java
public record ErrorDetail(String grid, String rowKey, Integer rowIndex,
                          String field, String code, String message) { ... }
```

```java
// 그리드 행 단위 에러
ErrorDetail.ofGrid("master", rowKey, "qty", "E001", "수량은 필수입니다.");                 // 5-arg
ErrorDetail.ofGrid("master", rowKey, rowIndex, "qty", "E001", "수량은 필수입니다.");        // 6-arg

// 공통 에러 (그리드 무관)
ErrorDetail.of("E002", "유효하지 않은 형식입니다");
```

| 정적 팩토리 | 시그니처 | 용도 |
|---|---|---|
| `of(code, message)` | 2-arg | 공통/전역 에러 |
| `ofGrid(grid, rowKey, field, code, message)` | 5-arg | 그리드 행 단위 (rowIndex 생략) |
| `ofGrid(grid, rowKey, rowIndex, field, code, message)` | 6-arg | 그리드 행 단위 + 인덱스 |

CactusResponse.errors 배열에 직렬화되어 FE 가 그리드 셀 단위 에러 표시 가능.

## 7. ResponseMeta 정적 팩토리

`ResponseMeta` 는 **record + 정적 팩토리** 로만 제공된다 (Builder 없음).

```java
public record ResponseMeta(String txId, boolean success, String code, String message) {
    public static ResponseMeta success(String txId);                                  // success=true, code="0000"
    public static ResponseMeta success(String txId, String message);
    public static ResponseMeta error(String txId, String code, String message);       // success=false
}
```

`CactusResponse` 는 Builder 패턴이지만, ResponseMeta 는 record 이므로 직접 인스턴스 생성 후 `new CactusResponse.Builder(meta).data(...).grids(...).errors(...).build()` 로 조립.
