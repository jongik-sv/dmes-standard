## 3. 라벨 판정 기준

- `_개발완료`: cactus-core 소스에 핵심 기능이 실제로 동작하는 상태. 부분 미구현이 있으면 본문에 명시.
- `_미개발`: 핵심 클래스/엔드포인트가 cactus-core 소스에 존재하지 않음. 부분 흔적은 본문에 표기.
- `_참고`: 의사결정 맥락·아키텍처·로드맵 보존용. 구현 여부와 별개로 보관.

## 4. 사용 가이드

- **신규 개발자 첫 입문**: 90 (로드맵) → 02 (패키지) → 03 (OasisController) → 04 (보안) 순.
- **명세 레퍼런스**: 01~08 정리본을 먼저, 더 깊이는 원본 docs/CACTUS_*.md 또는 docs/05-개발-상세설계.md.
- **신규 모듈 만들기**: 93 (모듈 셋업) → 92 (shared/portal 분리) → 03 (BPMN 통합).
- **미개발 항목 도입 검토**: 90 (로드맵) → 해당 미개발 정리본(10~19).

## 5. 메타

- 정리본 라인 수 합계: 약 2,500~3,000줄 (원본 약 12,000줄 대비 약 25% 압축)
- 작성 기준 cactus-core 버전: `com.dongkuk.dmes:cactus-core:1.0.18-SNAPSHOT` (2026-04-27 기준)
- 패키지 루트: `com.dongkuk.dmes.cactus.*`
- AutoConfiguration 7종 (META-INF/spring 등록): CactusAutoConfiguration, SecurityAutoConfiguration, CactusAuthAutoConfiguration, CactusWebSecurityAutoConfiguration, AuditAutoConfiguration, OasisAutoConfiguration, InboundAutoConfiguration
- BE 컨트롤러 URL: `/oasis/{serviceId}/{action}` (고정), `/service/{serviceId}`, `/query/{queryId}`, `/lov/master|query|service/...`
- 향후 갱신: cactus-core 신규 기능 추가/제거 시 해당 정리본 라벨 갱신 (90 로드맵 동시 갱신).
- 2026-04-27 정정 이력: 패키지 풀패스 (com.dongkuk → com.dongkuk.dmes), AuthController 부재 명시, URL 폐기 안 정정, ResponseMeta record 명시, JWT TTL 기본값 정정 (28800/86400초), CactusProperties 필드명 (`*-expiry`), 필터 등록 위치 (CactusWebSecurityAutoConfiguration), service_tag 자동/수동 영역 분리.
