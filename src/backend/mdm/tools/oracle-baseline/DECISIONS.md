# mdm Oracle 기준선 결정표 (자동 생성)

`gen_oracle_baseline.py` 가 V1 과 함께 만든다. 직접 고치지 않는다. 원천 V1__baseline.sql ~ V23__rule_set_ver_call_set_ids.sql, SHA-256 `0804799aa3d45636`.

## 규칙

| SQLite | Oracle | 비고 |
|---|---|---|
| `VARCHAR(n)` | `VARCHAR2(n CHAR)` | SQLite 는 길이를 강제하지 않았다. 로컬 DB 실측에서 넘는 값 없음 |
| `TEXT` | `VARCHAR2(4000 BYTE)` | 크기 상한이 없는 JSON·요청 원문만 `CLOB`(보정 패치) |
| `TEXT` 업무 일시(이름 `^(APPLY_FROM|APPLY_TO|VALID_FROM|VALID_TO|[A-Z_]+_AT)$`) | `TIMESTAMP(6)` | KST `yyyy-MM-dd HH:mm:ss`. 열린 끝 기본값은 `TIMESTAMP '9999-12-31 00:00:00'` |
| `TIMESTAMP`(감사 `C_AT`·`U_AT`) | `TIMESTAMP(6)` | Instant 매핑은 레인 간 결정 대기 |
| `INTEGER` / `BIGINT` | `NUMBER(10)` / `NUMBER(19)` | FK 자식은 부모 형을 따른다 |
| `INTEGER PRIMARY KEY AUTOINCREMENT` | `NUMBER(19) GENERATED BY DEFAULT ON NULL AS IDENTITY` | 적재 뒤 `START WITH LIMIT VALUE` 로 다시 맞춘다 |
| BOOLEAN(`INTEGER` 0/1) | `NUMBER(1)` | 보정 패치 |
| `NUMERIC(p,s)` | `NUMBER(p,s)` | |
| `CHECK (json_valid(X))` | `CHECK (X IS JSON STRICT)` | NULL 은 통과 |
| 부분 UNIQUE 인덱스 | 함수 기반 UNIQUE 인덱스 `CASE WHEN 조건 THEN 컬럼 END` | |
| FK 가 가리키는 고유 인덱스 | 같은 이름의 `UNIQUE` 제약 | ORA-02270 대비 |
