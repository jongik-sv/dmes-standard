# 드문 경우 (--only 옵션 · 대상 저장소)

> 출처: SKILL.md 의 「--only 옵션」·「대상 저장소」 절을 옮김. 아래 글은 원문 그대로.

## --only 옵션

해당 Phase 만 실행. 서버 보고·state.json 갱신 없음 (부분 실행 ≠ 상태 전진).
현재 state phase 와 다른 Phase 지정 → 산출물 덮어쓰기 위험 경고 + 사용자 확인 후 진행 (예: build 완료 상태에서 `--only design` 은 design.md 덮어씀).

## 대상 저장소

현재 작업 디렉터리 repo 에서 작업. 올바른 폴더에서 실행 = 호출자 책임 (저장소↔프로젝트 매핑 자동화는 보류된 설계 — 메모리 dflow-ops-structure 참조).
- wbs-web 자신이 대상이면 G1(마이그레이션 혼합)·G2(UI 위험 파일)·G4(마이그레이션 리허설)를 사용자에게 사전 경고.
- 마이그레이션 포함 작업은 done 요약에 명시: done 이후에도 스테이징 리허설 없이는 main 에 못 감.
