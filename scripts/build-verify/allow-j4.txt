# A = logic3(③ 결과), B = j4(C1 78d32000 + C2 89911003 이 들어간 커밋). A 가 B 의 바로 앞 커밋이 아닐 수 있다(경고는 정상).
# 의존성 파일(deps/·buildEnvironment/·configurations/)에는 패턴이 없다 — 그쪽 차이는 모두 위반.

# 줄 형식은 dump-settings.init.gradle 241행 'inputs.files <이름> normalizer=… optional=… type=… behavior=… = [정렬된 리포 상대경로]'
# 그대로이고, 값(경로 목록)까지 고정했다.

# 덤프 위치: mdm 모듈 api 프로젝트 settings 의 '## Test :api:test' 섹션 한 줄(v-mdm-1 147행에서 확인 — 이 이름은 파일에 한 줄뿐).
